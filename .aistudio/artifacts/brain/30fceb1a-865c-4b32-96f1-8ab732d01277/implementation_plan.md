# Catalog JSON Import & Backup Restore

A robust, schema-validated backup and restore workflow for IdeaFactory that allows developers to import previously exported JSON catalogs, preview imported items, and resolve conflicts safely without data loss.

## User Review & Critical Decisions

> [!IMPORTANT]
> Please review the conflict resolution strategy and schema validation rules below before approving execution.

- **Confirmed Decision 1**: Prioritizing the **Catalog JSON Import and Backup Restore** workflow from the previously deferred features.
- **Confirmed Decision 2**: Creating a comprehensive implementation plan spanning the client drag-and-drop modal, strict schema sanitization, and backend batch restore endpoint.
- **Decision Gate (Import Conflict Handling)**: When an imported item matches an existing idea by `id` or exact `title`:
  - *Option A (Default - Merge & Update)*: Update existing ideas with imported data while preserving local bookmark statuses, and append any novel ideas.
  - *Option B (Append with New IDs)*: Re-key collisions so both existing and imported versions coexist.
  - *Option C (Clean Overwrite)*: Completely replace the active catalog with the imported backup file (with explicit double-confirmation).
  - *Recommendation*: Provide the user an interactive choice in the import preview modal with **Merge & Update** pre-selected.

## 1. Overview & Core Concept

- **What It Does**: Adds a dedicated **Import Catalog** action in the Repository view alongside "Export Catalog (JSON)". Users can drag-and-drop or select any `.json` file generated by IdeaFactory (or external backup). The system parses and validates the schema, displays an inspection summary (number of full specs, drafts, tags, language breakdown, and detected duplicate conflicts), and executes the import with progress feedback.
- **Target Audience / Persona**: Software engineers and system designers building catalogs of project concepts across multiple sessions or devices who need to restore backups or combine curated idea collections.
- **Key Value**: Closes the data-loss loop caused by the server's in-memory storage model without requiring complex cloud database setups, allowing offline persistence via file portability.

## 2. User Experience & Visual Design

### Key User Flows

1. **Triggering Import**:
   - In **The Repository** header, next to "Export Catalog (JSON)", a clean "Import Backup" button (`Upload` icon) opens the **Import Catalog Modal**.
2. **File Selection & Drag-and-Drop**:
   - A dropzone with subtle dashed border (`border-slate-700/60 hover:border-indigo-500/50`) accepts `.json` files.
   - Immediate client-side validation gives instant feedback on file format and parse errors before sending data to the server.
3. **Pre-Import Inspection & Conflict Preview**:
   - Once a valid file is parsed, the modal transitions to a **Catalog Diff & Preview** card showing:
     - Total items detected (split by Full Specifications vs. Quick Drafts).
     - Breakdown of languages and complexity levels.
     - Collisions detected (matching `id` or title with existing catalog items).
   - Conflict resolution selector: **Merge & Update (Recommended)**, **Keep Both (Append as New)**, or **Replace Entire Catalog**.
4. **Execution & Toast Notification**:
   - Clicking "Restore Catalog" dispatches the batch import to `/api/ideas/import`.
   - The repository updates immediately with the imported ideas.
   - A success banner or toast reports: *"Successfully imported 14 ideas (3 updated, 11 added)"*.

## 3. Key Product Decisions & Trade-Offs

### Decision 1: Hybrid Client Validation + Server-Authoritative Merge
- **Chosen Approach**: Validate JSON structure and schema compatibility in the client before submission, and have the Express backend perform the actual atomic merge in `server.ts` via `POST /api/ideas/import`.
- **Why**: Instant user feedback on malformed files without unnecessary server round-trips; server-side merge ensures consistent state for all connected browser tabs and preserves API atomicity.
- **Alternatives Considered**: Client-only merge via sequential `POST /api/ideas` requests would cause excessive HTTP requests (e.g. 50 individual calls for a 50-item backup) and partial failure states.

### Decision 2: Schema Compatibility for Both Full Specs & Quick Drafts
- **Chosen Approach**: Support importing both complete `IdeaItem` records and lightweight draft `IdeaItem` records (created by the Quick Idea Generator), normalizing missing fields (e.g. default empty challenges/roadmap for drafts) with robust fallbacks.
- **Why**: Allows users to export from the Repository and import back without schema validation errors on draft items.
- **Alternatives Considered**: Rejecting incomplete drafts would break backups created when the catalog contains saved quick ideas.

### Data Model & Validation Schema

```typescript
// Incoming import payload shape
export interface CatalogImportPayload {
  mode: 'merge' | 'append' | 'replace';
  ideas: Partial<IdeaItem>[];
}

// Result returned from backend
export interface CatalogImportResult {
  success: boolean;
  importedCount: number;
  addedCount: number;
  updatedCount: number;
  totalCatalogCount: number;
  ideas: IdeaItem[];
}
```

### Interactive Component & State Mapping

1. **`ImportCatalogModal.tsx`**:
   - `file`: Currently loaded `File | null`.
   - `validationResult`: `{ isValid: boolean; errors: string[]; parsedIdeas: IdeaItem[]; duplicates: number }`.
   - `importMode`: `'merge' | 'append' | 'replace'`.
   - `isImporting`: boolean spinner state during API call.
2. **`ideasApi.ts`**:
   - `importCatalog(payload: CatalogImportPayload): Promise<CatalogImportResult>`.
3. **`server.ts`**:
   - Add endpoint `POST /api/ideas/import`.
   - Validates that body is either an array of ideas or an object containing `{ mode, ideas }`.
   - Normalizes every idea to guarantee valid structure (`id`, `title`, `language`, `domain`, `complexity`, `tags`, etc.).
   - Returns full updated catalog so frontend state stays perfectly synced.
4. **`RepositoryView.tsx`**:
   - Mounts "Import Backup" button in header.
   - Refreshes catalog and displays success toast with import breakdown upon completion.
